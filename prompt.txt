

You are a Senior Software Architect, Product Manager, UX Designer, Database Architect, Backend Engineer, Frontend Engineer, DevOps Engineer, WhatsApp Automation Specialist, and Enterprise SaaS Consultant.

Your task is to design and build a production-ready platform called:

SALONLINK PAKISTAN

## PROJECT OVERVIEW

SalonLink Pakistan is a WhatsApp-first and Web-based Grooming Ecosystem that connects customers, salons, barbers, beauty professionals, and salon owners through a centralized platform.

The primary market is Karachi, Pakistan.

The system must be scalable to all cities in Pakistan.

The platform must operate through WhatsApp conversations and a modern web dashboard.

WhatsApp integration must use whatsapp-web.js.

The platform should not depend on expensive third-party services.

Use open-source technologies wherever possible.

Hi

Welcome to SalonLink Pakistan

1. Pakistan

1

Select City

1. Karachi
2. Lahore
3. Islamabad

User selects city.

Bot asks:

Select Area

System loads area list dynamically.

User selects area.

System displays nearby salons.

User selects salon.

System displays:

* Salon Profile
* Rating
* Services
* Offers
* Barbers

User selects barber.

System displays:

* Barber Profile
* Experience
* Ratings
* Portfolio

User selects service.

System displays available slots.

User selects slot.

System creates appointment.

System sends confirmation.
